# `docs/_memory/` — セッション記憶のバックアップ（新しいチャットへの引き継ぎ用）

> **これは何か**: Claude Code のプロジェクト記憶を**リポジトリへ書き出したもの**（Gear-vk と同じ運用）。
> 長期間チャットを使わずに履歴が失われても、ここを読めばそのまま引き継げるようにするのが目的。

## 新しいチャットで最初にやること
1. **`PSK_README.md`**（索引）→ **`docs/2_impl/PSK_IMPLEMENTATION_STATUS.md`**（現在地）の順に読む。
2. 本フォルダの **`_INDEX.md`** に目を通し、気になった項目だけ本文を開く。

## ⚠ 読むときの注意
- **記憶は「書かれた時点のスナップショット」**。ファイル名・関数名を含むものは、現在のコードに実在するか確かめてから信じる。
- **仕様の正は `docs/1_spec/PSK_*.md`**。記憶と食い違ったら仕様側が正。
- Gear-vk から持ち込んだ写しは、Gear-vk のパスや設定値で書かれている。中身ではなく**教訓**として読む。
