**バッテリーを摘出した GPD WIN4 は、再起動後にグラフィックが認識されないことがある**。
復帰には強制再起動を何度も繰り返す必要があり、その間**画面に何も出ない**。

**Why:** 「進捗が分からないまま強制再起動する」ことになるのが危険。とくに
**Windows のインプレース修復アップグレードや大型更新**は、複数回の再起動を挟み、
オフライン工程では起動画面の進捗表示しか出ない。画面が出なければ
「作業中」と「ハング」の区別がつかず、**アップグレードの最中に強制再起動＝起動不能**になり得る。

**How to apply:**
- **再起動を複数回挟む作業をこの機体に提案しない**（インプレース修復／機能更新／BIOS 更新など）。
  やむを得ず必要なら、リスクを明示してユーザーに判断してもらう。
- Linux ホストが要るときは **Windows を書き換えず、ライブ USB から起動する**方を先に検討する
  （画面が出なくても「中途半端に書き換わった OS」が存在しないので、電源を落とすだけで済む）。
- 2026-08-25 に、この理由で **WSL 復旧のためのインプレース修復を中止した**。
  そもそも目的（Buildroot を回す Linux ホスト）は Pi5＋USB SSD で達成できたため、
  Windows 側の修復は何もブロックしていなかった。→ [[linux-pi5-port-working]]
