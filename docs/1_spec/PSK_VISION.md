## 1. 概要

### 1.1 ゴール
: 🟢 配信の音まわりを **「1つの小さなソフト＋OBS」で完結**させる（2026-10-14 ユーザー要望）。
: 🟢 **主な狙いは可搬性の改善**（GPD WIN4＋SSL 12 から X390＋Play! 3 へ）。今の環境の遅延に不満は無い（2026-10-14 ユーザー回答）。
: 🟢 **自分用**。他の人には配らない（2026-10-14 ユーザー回答）。
: 🟢 **到達点: 最低限のスペックの Windows 機に、Sound Blaster Play! 3・EarPods・iPhone を挿せば始められる環境**（2026-10-14 ユーザー要望）。X390 はその1台目。

- 🟢 **当面動けばよいのは ThinkPad X390（後期版・第10世代 Core i5）の1台だけ**（2026-10-14 決定）。「最低限のスペック」の一般化は後回し。
- 🟢 **できるだけ内製する**。外部ツールは**有無を検知して、無ければダウンロード先へ案内する**程度でよい（2026-10-14 決定・`PSK_ENGINE §8`）。
- 🟢 **イヤホンマイクは EarPods（3.5mm）で完結させたい**（2026-10-14 ユーザー要望）。
- 🟢 **EarPods は Play! 3 のヘッドホン端子にそのまま挿せる**: ヘッドホン端子は CTIA 配列の4極（ステレオのヘッドホン＋モノラルのマイク）。EarPods も CTIA[^play3-spec]。
  - Play! 3 の差し口は2つ（4極のヘッドホン端子と、マイク端子）。**ヘッドホン端子のマイクとマイク端子は同時には使えない**。ダイナミックマイクには非対応。
  - マイク入力は最大 24bit／48kHz・モノラル。24bit／48kHz にするには専用のコントロールパネルが要る。
  - 🔴 マイクへの給電電圧・入力インピーダンス・マイクのゲインの段数は公開資料に無い。
- 🔴 iPhone に挿すとボーカルにも使えそうなほど綺麗だが、PC ではいまいちになる（ユーザーの観察）。配列（CTIA）は原因から外れる。残る候補はマイクへの給電電圧・ゲインの段取り・電源ノイズ・自動の加工で、未特定。
- 🟢 iPhone の役割は VTube Studio のトラッキング。**つなぎ方は有線（USB）または Tailscale 経由**（2026-10-14 決定）。本ツールの範囲外だが、環境としては含む。

## 3. スコープ

### 3.1 🟢 必須の要件（2026-10-14 ユーザー要望）
- **ASIO** でインターフェースとやり取りし、**できるだけ低遅延のモニター**をヘッドホンへ返す。
- 同時に **VB-CABLE** へ音を出し、OBS へ渡す。出力方式は **WASAPI 共有または DirectSound**。
- ＝ **ASIO と WASAPI 共有（または DirectSound）を同時に開けること**。

### 3.2 🟢 決まったこと（2026-10-14）
- 🟢 **デスクトップ音と通話も本ツールで拾う**（マイク1本だけのツールにはしない）。
- 🟢 **操作はすべて X390 上で行う**（リモート操作は作らない）。
- 🟢 **デスクトップ音・通話は仮想ケーブル（VB-CABLE 類）経由で拾う**（`PSK_ENGINE §2.2`）。
- 🟢 **出力先（ストリーム）は必要な数だけ増やせる**。OBS 向けのほか、Discord などの通話アプリのマイク向けにも出す（`PSK_ENGINE §2.3`）。
- 🟢 **OBS へは基本的に全部を混ぜた1本で送る**（`PSK_ENGINE §2.4`）。
- 🟢 **低遅延を求めるのはヘッドホンへのモニターだけ**。それ以外の出力はバッファを切り詰めなくてよい（`PSK_ENGINE §3.3`）。

### 3.3 🟡 未決
- 🟢 **ヘッドホンに返す音**: ヘッドホンも出力の1つとして、送り量の表（`PSK_ENGINE §2.1b`）で何を混ぜるかを決める。
  🔴 Creative ASIO 使用中に、本ツールを通らない Windows の音が Play! 3 から直接鳴るかは未検証（`PSK_ENGINE §3.1`）。
- 🟢 **起動したら、ボタン1つで「あとは OBS の配信開始を押すだけ」の状態まで持っていく**（2026-10-14 ユーザー要望・`PSK_ENGINE §7`）。
- 🟡 その他の機能（録音・プリセットの切り替え・自動起動など）は、今のところ要望なし。

## 4. 🟡 合格基準（未決）
- 🟢 モニターの遅延は**今の環境（FL Studio＋SSL 12）で不満が無い**ので、数値の目標は置かず、X390＋Play! 3 で実測して「不満が出ないこと」を見る（2026-10-14）。⚠ 軽量化でバッファを切り詰める方針（`PSK_ENGINE §1.1`）はそのまま。
- 🟡 OBS 側の遅延の扱い（OBS の同期オフセットで合わせる前提でよいか）。
- 🟡 連続運転の目安（配信1回分の時間で音切れ0回、など）。
