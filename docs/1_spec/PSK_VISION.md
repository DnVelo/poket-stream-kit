## 1. 概要

### 1.1 ゴール
: 🟢 配信の音まわりを **「1つの小さなソフト＋OBS」で完結**させる（2026-10-14 ユーザー要望）。

### 1.2 分業
: 仕様はユーザーと Claude Code で一緒に決める。コードは Claude Code が担う。進め方と資料の型は Gear-vk から流用。

## 3. スコープ

### 3.1 🟢 必須の要件（2026-10-14 ユーザー要望）
- **ASIO** でインターフェースとやり取りし、**できるだけ低遅延のモニター**をヘッドホンへ返す。
- 同時に **VB-CABLE** へ音を出し、OBS へ渡す。出力方式は **WASAPI 共有または DirectSound**。
- ＝ **ASIO と WASAPI 共有（または DirectSound）を同時に開けること**。

### 3.2 🟢 決まったこと（2026-10-14）
- 🟢 **デスクトップ音と通話も本ツールで拾う**（マイク1本だけのツールにはしない）。
- 🟢 **操作はすべて X390 上で行う**（リモート操作は作らない）。
- 🟢 **デスクトップ音・通話は仮想ケーブル（VB-CABLE 類）経由で拾う**（`PSK_ENGINE §2.2`）。
- 🟢 **出力先（ストリーム）は必要な数だけ増やせる**。OBS 向けのほか、Discord などの通話アプリのマイク向けにも出す（`PSK_ENGINE §2.3`）。
- 🟢 **OBS へは基本的に全部を混ぜた1本で送る**（`PSK_ENGINE §2.4`）。
- 🟢 **低遅延を求めるのはヘッドホンへのモニターだけ**。それ以外の出力はバッファを切り詰めなくてよい（`PSK_ENGINE §3.3`）。
