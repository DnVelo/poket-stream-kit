## 3. 更新履歴（新しい順）

### 2026-10-14 — 仕様の第6回
- 出力ストリップを置く（入力は左寄せ・出力は右寄せ）・残り本数アイコンはプログラム名の右隣・自分用・主な狙いは可搬性・遅延は今に不満なし・起動後ボタン1つで配信可能な状態に、を記録。メーターは規格ベースの案を出した。

### 2026-10-14 — 仕様の第5回（画面）
- 画面はチャンネルストリップを横に並べる形（ユーザーのスケッチ）。全チャンネル同じ形・エフェクトは全チャンネル・送り先はフェーダーの右に縦のボタン・ケーブルの残り本数アイコン・画面は素の Win32 の標準コントロール（一番軽い手段として・手本は Gear-vk の gear-gui）、に決定。

### 2026-10-14 — 仕様の第4回
- ミキサーの形（入力×出力の送り量の表・ケーブルは入出力合わせて5本まで）に決定。
- T-De-Esser はできれば使う。内製できるなら聞き比べて決める。

### 2026-10-14 — 仕様の第3回
- ASIO は Zig から直接呼ぶ、それ以外の入出力は miniaudio、に決定。RtAudio は Android に効かないので見送り。
- 今のチェーン（記憶ベース）を記録。RX は De-noise だけ・rovee は g200kg 製で必須（内製も検討）・EQ/コンプ/マキシマイザーはこだわりなし、を記録。Soundgoodizer など FL 内蔵のプラグインが外で使えない問題を🔴として記録。
- rovee の DLL を調べ、32bit 専用の VST2 と判明（64bit のホストからは直接読めない）。`[midicc]` の意味（設定値か MIDI CC の割り当てか）は未確定（一度「割り当て」と断定したが根拠が足りず取り消し）。

### 2026-10-14 — 仕様の第2回／叩き台の削除
- デスクトップ音・通話は仮想ケーブル経由／出力先は必要な数だけ増やせる／OBS へは全部を混ぜた1本／低遅延はモニターだけ、に決定。
- JUCE の叩き台を削除した。クロック橋渡しの方式とテスト結果は `PSK_ENGINE §3.2` へ移した。

### 2026-10-14 — 仕様の第1回
- デスクトップ音と通話も拾う／ASIO は Creative ASIO／操作は X390 だけ／構成は Zig ＋ C++（極力 Zig・軽量化でバッファを切り詰める）に決定。
- JUCE の叩き台は不採用になった。

### 2026-10-14 — 叩き台の作成と、Gear-vk の運用の流用
- 仕様を決める前に JUCE 版の叩き台を作って push した（ユーザーの指摘で中断）。
