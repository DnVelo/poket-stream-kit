# poket-stream-kit

配信の音まわりを「小さな VST ホスト 1本＋OBS」で完結させるための自作ツール（Windows / ThinkPad X390 ＋ Sound Blaster Play! 3）。

- ASIO（Creative ASIO）で、低遅延のモニターをヘッドホンへ返す
- 仮想ケーブル（VB-CABLE 類）経由で、デスクトップ音と通話を取り込む
- 処理後の声と取り込んだ音を混ぜ、OBS や通話アプリへ送る
